cAIsdev — симулятор обратной связи от стейкхолдеров для продуктовых команд
Сделано на курсе vibe coding
Проблема
  • У продукта нет единого заказчика — обратная связь со стороны бизнеса практически отсутствует
  • Компаний-клиентов много, по каждому черновику не достучишься
  • Каждый в команде общается с ИИ по-своему — единого формата нет
  • Инсайты из чатов с ИИ хранятся разрозненно и не накапливаются
Решение
  • Загружаешь документ — ЧТЗ, концепцию, user story
  • Выбираешь фазу: Концепция / Требования / Готовая функциональность
  • 10 персон-стейкхолдеров дают фидбек от своего лица одновременно
  • Единый формат хранения инсайтов — экспорт в CSV
  • Персоны обучены на специфике HRM-рынка, а не универсальные
Как сделано
  • Написано с нуля с помощью Claude Code — без опыта разработки
  • Node.js + Express, Supabase (PostgreSQL), Docker
  • Автодеплой: push в GitHub → сервер обновляется сам
  • Gemma 4 через OpenRouter — прямой Google API недоступен с РФ-сервера
  • Rate-limit защита: ретрай с бэкоффом, задержки между вызовами
Почему не...
  • Реальные касдев-интервью—долго и дорого, не масштабируется
  • Экспертные ревью внутри команды—субъективно, нет взгляда со стороны бизнеса
  • Обычный ИИ без ролей—нет структуры, каждый задаёт разные вопросы, инсайты теряются
Для кого
  • Аналитики без прямого доступа к заказчику
  • Продавцы, готовящие демо для клиента
  • Владельцы продукта на этапе проверки гипотез

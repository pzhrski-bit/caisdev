# Роли пользователей — cAIsdev

---

## Кто использует инструмент

| Роль | Как использует | Основная потребность |
|------|--------------|---------------------|
| **Продуктовый аналитик** | Загружает ЧТЗ / user story перед передачей в разработку | Проверить полноту требований глазами стейкхолдеров |
| **Бизнес-аналитик** | Загружает концепцию или результаты анализа | Получить реакцию бизнеса до встречи |
| **PM / PO** | Загружает роадмап или описание фичи | Приоритизировать через призму стейкхолдеров |
| **Пресейл / аккаунт-менеджер** | Загружает КП или демо-материалы | Предвосхитить возражения клиента |

---

## Как роль влияет на поведение инструмента

### При указании роли пользователем:
Персоны адаптируют **уровень детализации** и **терминологию**:

- **Аналитик → персоны** говорят про полноту, трассируемость требований, граничные случаи
- **PM → персоны** говорят про бизнес-ценность, приоритеты, конкуренцию за ресурсы
- **Пресейл → персоны** говорят про ROI, риски, сроки окупаемости, сравнение с конкурентами
- **Разработчик → персоны** говорят про нефункциональные требования, интеграции, SLA

### Реализация в промпте:
В начало системного промпта каждой персоны добавляется блок:

```
## Контекст взаимодействия
Сейчас с тобой разговаривает [роль]. 
Адаптируй уровень детализации: [детали для конкретной роли].
```

---

## Свободный контекст (дополнительное поле)

Помимо роли, пользователь может указать:
- Что именно хочет проверить ("меня больше всего беспокоит безопасность")
- Что уже обсуждалось ("с HRD мы уже говорили, этот вопрос закрыт")
- Ограничения ("у нас нет бюджета на интеграцию с SAP")

Этот контекст передаётся в user message, не в system prompt.
